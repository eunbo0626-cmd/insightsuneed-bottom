# 저점판독기 (투자 엔진 EPISODE 02 · 너에게 필요한 인사이트)

기업 상태: 싸진 건가, 망가진 건가?
공시(OpenDART·SEC EDGAR)와 일별 시세로 지금의 저점을 판독하는 참고용 웹앱입니다.

## 페이지
- `/k/005930` 국내 상장사
- `/u/NKE` 미국 상장사

## 판독 기준
0. 판독 보류: 중대 공시, 투자 전 체크 등급 고위험, 망하는 시나리오 '매우 높음'
1. 가격 위치: 52주 고점 대비 하락률, 3년 범위 내 위치, 변동성 대비 낙폭, 지수 대비 6개월 성과
2. 기업 상태: 주가 하락폭 vs 이익 변화, PER·PBR의 최근 결산 시점 대비, 적자 전환·현금흐름·이자보상·재무안정성
3. 차트 흐름: 신저가 멈춤, 저점 높아짐, 거래량 균형, RSI 다이버전스, 이동평균 회복 (5개 중 3개 이상 = 진정)
4. 수급·이벤트(보조): 자사주 취득, 임원·대주주 지분 변동, 투매성 거래 후 가격 유지

## 데이터 갱신
- 시세: 1시간마다 (국내 네이버 금융 일별 시세, 미국 Yahoo Finance)
- 공시·재무: 6시간마다

## 실행
```bash
npm install
cp .env.example .env.local   # DART_API_KEY 입력
npm run build && npm start
```

본 서비스는 공개 자료를 규칙에 따라 계산한 참고 정보이며, 매수·매도 권유나 투자자문이 아닙니다.
